AGREED PROBLEM DESCRIPTION
  One agent in a walled environment must reach location L5.  Four gates divide
  the environment; each opens only while its receivers are lit by a beam of the
  receiver's colour.  Beams come from two wall transmitters and are relayed by
  two movable connectors and one floor repeater.  A switch and a recorder are
  present; neither has an identified useful effect (open items 1 and 2).
  The description is agreed by the user except for those two items.

USER OBJECTIVE AND ANSWER IDENTITY
  Answer: one action sequence ending with the agent at L5.
  Preference: fewest actions.  Any one shortest sequence is acceptable.
  Depth: Claude estimates and runs searches to reasonable depths later
  (user decision 2026-11-14); no user-supplied maximum for this problem.

STRUCTURE AND GROWTH
  10 locations, 2 connectors, 8 fixtures, 4 gates, 1 switch, 1 recorder.
  A situation is: agent location and what it holds; each connector's location,
  pairings and pending selections; switch state; and, if recording is modelled,
  the recorder layer.  Lit hues, active receivers, open gates and active
  crossings follow from these.
  Choices per situation: move to a reachable location, pick up / select termini
  / put down a connector, toggle SW1 (at L1), recorder actions (at L2).
  Selection subsets are the main source of branching.  Moves are reversible,
  so repeated situations must be merged.

  D3  Include beam crossing.  It is required: it is what makes G4 unopenable
      from the start.
  D4  Graph search merging repeated situations, shortest plan.
  D5  SW1: carried as a switch toggled from L1 with no modelled effect on any
      gate (user tests: no gate, no recorder change).  Open item 1.
  D6  Recorder: user tests show (a) recording auto-stops at 1.5 s, (b) without
      a pause there is no playback and no ghost, and the agent is not returned
      to the recorder, (c) with a pause there is a playback in which the ghost
      runs for at most 1.5 s to the agent's recorded position and disappears,
      (d) any number of cycles.  How to model this is open item 2; the user
      holds that the recorder must be the key to opening G4.
  No reduction of the answer set is proposed.
