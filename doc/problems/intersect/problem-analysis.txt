USER OBJECTIVE AND ANSWER IDENTITY
  Any plan reaching the goal; a shortest plan preferred (unit action cost).
  Plans are action sequences; only length matters for comparison.

INTENDED RULES AND EXAMPLES
  Standard talos tech rules (talos-reference 1.4, 1.8), confirmed by user:
  - Agent walks freely within an area; walls, windows, closed gates block it.
  - No reach through any window: the agent cannot pick up or place a connector across a
    window (all windows effectively barred); beams still pass windows.  (User, 2026-11-05.)
  - LD1 climb L3->L2 only, only when empty-handed.  Allowed: empty agent at L3 climbs to L2.
    Forbidden: agent holding a connector climbs; any descent L2->L3.
  - Agent carries one connector.  Pickup either drops links or keeps them (game option).
  - A connector has at most 3 links at any time, counting links it made and links other
    connectors made to it; links kept through a pickup still count.  (User, 2026-11-05.)
  - Connect: place held connector and link to 1-3 termini (transmitters, receivers, other
    connectors) structurally visible from any currently walkable location.
  - Connector takes the hue reaching it; two hues in the same layer -> unlit.
  - Receiver active while a beam of its own hue reaches it from a paired relay.
  - Any two crossing beams, of any hues, cut each other at the intersection.
  - Agent and connectors block beams passing within 1/2 unit.
  - Example: an unlinked connector put at L6 holds P1; G4 then opens iff R4r is also active.

STRUCTURE AND GROWTH
  Structural fact (deduction from layout): the only agent route into L7 is
  L1 -G1-> central -G2-> east -G3-> west/north -G4-> L7.  LD1 only returns the agent
  from east to central.  Every plan therefore passes G1, G2, G3, G4 in that order, each
  open at its time of passage.  C2 (at L2) is unreachable before G1 is first opened; C3 (at L3)
  before G2 is first opened.
  Size: 1 agent, 3 connectors, 7 locations, 6 apparatus, 4 gates, 1 plate, 1 ladder.
  History irrelevant to future legality: state fully determines continuations.
  Growth: connect branching = reachable locations x link subsets (92 for 8 termini, cap 3);
  subsets grow ~cubically in termini; locations, gates grow linearly.
