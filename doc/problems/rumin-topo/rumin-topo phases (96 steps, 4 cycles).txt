RUMIN-TOPO -- 96-action solution, four recorder cycles.
Source: rumin-topo solution (96 steps, 4 cycles).lisp

Sectioning follows PARSE-RECORDER-PATH and PRINT-RECORDER-CYCLE-REPORT in
tech/-recorder-solution.lisp; this transcribes that decomposition, with long MOVE
routes wrapped and per-cycle metrics (elapsed time, value change) omitted -- they
need a replay, not a reading of the path.  Live agent = AGENT1; ghost agent =
AGENT1*.  Numbers are positions in the 96-action VALIDATE-SOLUTION list.

Each phase has exactly one actor:

Setup phase     -- actions accumulated before this cycle's START-RECORDER.
Recording phase -- AGENT1* only, headed by AGENT1's START-RECORDER and closed by
                   the ending.  A (PAUSE) marks a pause point AGENT1 creates
                   while recording; it stands where a live block ran and nothing
                   was captured.
Playback phase  -- AGENT1 only.  A (RESUME) marks where AGENT1 releases the ghost
                   to run the recorded steps following that pause point; the ;;
                   annotation names them.  START-RECORDER and a normal
                   STOP-RECORDER are not playback actions.

(PAUSE) and (RESUME) stand one-to-one: every pause point created during recording
is released exactly once during playback.  A normal STOP-RECORDER counts as
remaining recorded action, so a live block that ends the window still earns a
pause point.
