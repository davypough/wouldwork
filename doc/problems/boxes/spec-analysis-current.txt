2. CURRENT MODEL AND REQUIREMENT MAPPING

Objective: one globally shortest sequence of unit pickup, placement and
gate-crossing actions; tied optima need not all be returned. Walking within an
area is free and uncounted.

Given instance, preserved unchanged: agent1, box1 and box2, area1-area4,
plate1-plate3, gate1-gate3; agent1 and box1 start in area1, box2 in area2;
gate1 joins area1/area2, gate2 area1/area3, gate3 area3/area4; plate1 and plate2
are in area1, plate3 in area3; plateN controls gateN. Goal: (loc agent1 area4).

Changing state:
- (loc object $area): the agent's area and each box's area. A box on a plate
  keeps its area; a held box has no area.
- (holding agent $box): the box the agent holds, if any.
- (on $box $plate :bijective): which box is on which plate, looked up either way.
Gate openness is derived from its controlling plate's occupancy (GATE-OPEN?);
no gate state is stored.

Static facts: gate endpoints, plate areas, the one-to-one plate/gate wiring,
and three facts derived at initialization -- each area's plate list, each
area's gate list, and each area's all-open crossing distance to area4.

Requirement -> implementation:
- Empty hands to pick up; carry at most one -> PICKUP requires no HOLDING fact;
  PLACE requires one.
- Local handling only -> PICKUP requires the box in the agent's area; PLACE uses
  only the agent's area and that area's plates.
- Ground storage unlimited; plate holds one box -> ground placement always
  allowed; plate placement only when CLEARTOP?.
- Recovering a box from a plate closes its gate immediately -> PICKUP retracts ON;
  openness is always derived, never stored.
- Cross an open incident gate either way, carrying allowed -> CROSS-GATE iterates
  the area's gate list, tests GATE-OPEN?, and moves only the agent; a held box
  has no area, so it moves implicitly.
- Each transition is one unit action -> three actions of cost 1; each legal
  alternative is emitted by its own ASSERT.

3. REDUCTIONS (agreed in problem-analysis.txt)

- No stepping onto plates: the lone agent cannot use its own temporary gate
  opening, so plate visits are omitted from the search model.
- Interchangeable boxes: boxes keep their names, and engine symmetry pruning
  (ww-set *symmetry-pruning* t) merges arrangements that differ only by box
  names. Distinct area/plate allocations remain distinct. Solutions name
  actual boxes.
- No repeated arrangements: GRAPH search keeps the cheapest arrival at each
  complete arrangement.

4. ENHANCEMENTS FOR LARGER INSTANCES

- Combined actions: PLACE emits ground and every empty local plate as separate
  alternatives; CROSS-GATE emits every open local gate.
- Local lists: AREA-PLATES and AREA-GATES are built once by
  INITIALIZE-TOPOLOGY-INDEXES, so actions consider only local candidates.
- Crossing bound: INITIALIZE-CROSSING-BOUNDS computes each area's all-open
  crossing distance to area4 (supplied values area1 2, area2 3, area3 1,
  area4 0; zero for disconnected areas). MIN-STEPS-REMAINING? returns it as a
  lower bound on remaining actions. The goal area appears in both the bound
  derivation and DEFINE-GOAL; change both together.
- Symmetry pruning: on for this problem. Whether its overhead pays off on
  larger instances is untested and belongs to the search advisor.
