METHOD IN FORCE
---------------
Node kinds S (state conditions), A (action), P (parameter grouping).
Status A active, O open, X excluded at creation, R refuted, D done.
Each non-X, non-R node carries f = depth + h, h from the landmark
heuristic H1.  Expand the open node with the smallest f; ties go to fewer
ghost conditions, then fewer gate conditions, then greater role
consolidation (H2).  Nothing is pruned on f: every exclusion rests on
logic -- T4 relevance, T7 and T13 dominance, the T15/T24 census,
contradiction -- never on a bound.  S nodes keep complete condition sets
(T4) and carry aliases N1, N2, ... in creation order.  A refuted node
keeps its header with status R, its cites, and a one-line
"REFUTED <date>: <reason>" beneath it.

H1 is revisable, and revision is not optional: a correction that changes
any f difference between OPEN nodes is applied and every affected f
recomputed before the next expansion.  A correction that shifts the
frontier uniformly is applied too but reorders nothing.

H3, the audit, runs at EVERY expansion, BEFORE the children are ranked --
A provenance, B delivery, C access, D session, E interference, F
dominance, G over-specification, H solution-independence.  A to D give h
increments; E, F and G change the node.  Each justification entry carries
an Audit line naming the checks that fired and those that ran clean.
Session 5's lesson for the audit: run check D (session) as a COUNT of
ghost bodies against the recording-side gates the ghost must pass (R16,
T23) -- that is what refuted thirty-two nodes at once.

H4, measurement: (SOLVE-SUBGOAL *START-STATE* <goal>) with a modest
cutoff gives an admissible lower bound by construction.  Never hand-build
a start state.  Ceiling from the true start: about cutoff 14 (17 took
395 s with 16 threads).  From a mid-problem state the ceiling is FAR
lower: see the instrument notes below.

H7, forward exact solving: H6 forbids BORROWED knowledge, not GENERATED
knowledge.  A landmark solution gives a number, a witness, a reachable
legal end state to chain from, and a shape.  CAVEAT on shape: one plan is
one witness; it shows what is possible, never what is necessary.  A
node may be refuted by a COUNT or a CODE READING, never by a witness.
The method ENDS when the two frontiers meet: a backward node whose
complete condition set is satisfied by a reachable state yields a whole
plan and is marked D.

H6, solution independence: no condition set, exclusion, landmark value,
expansion order or tie-break may cite a known solution.  H3 check H asks
at every node whether each reason could have been given on an unsolved
problem.

H5, session hygiene: when the dialogue outweighs the three state files, or

the files current, regenerate this prompt so that it alone carries the

2  Choose the start by what kind of answer you need: a PLAN from any
   legal start is a witness; an EXHAUSTION is sound only for that state;
   a LOWER BOUND on h needs *START-STATE*.  Derive intermediate starts
   by chain or replay, never by hand.

   predictions have been wrong about mechanism (K15, the alcove, the

4  Run at the smallest plausible cutoff; chain short milestones.
5  Read the TRACE, then the LISTINGS, then the NUMBER.
6  Feed back: a measured K replaces an argued one; record both values.
7  Disjointness: measure A, B, then A and B together (not yet run).
