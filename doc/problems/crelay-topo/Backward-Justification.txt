Crelay-Topo Backward Analysis -- Justification
==============================================

Companion to Backward-Tree.txt; labels match the tree.  Cites rules, facts,
lemmas, nogoods, and symmetries from Backward-Rules-Facts.txt.

Entry policy (for concision)
----------------------------
  - Entries exist only for nodes with status A, R, or D.  O nodes are
    described by their tree line; X nodes by their tree citation.
  - Each entry lists only what the node adds; inherited constraints are
    implied by the path from the root.
  - Any argument used at more than one node is promoted to a lemma (T) in
    Backward-Rules-Facts.txt and cited thereafter.
  - A refutation is recorded as a nogood (G) there, stated as the minimal
    conflicting constraint set, so other branches can be checked against it.
  - A full constraint snapshot appears only at declared checkpoints.

Entry format
------------
  <label>  <one-line claim>
    Uses:     R/F/T/G/Y labels
    Adds:     new constraints, in wouldwork syntax
    Cases:    child labels created (X children with citation)
    Why:      at most a few lines, only where citations are not enough
    Result:   status change; lemma or nogood recorded, if any
