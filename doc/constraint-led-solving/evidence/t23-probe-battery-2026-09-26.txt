2.2  Findings

  a. A held tray keeps HAS-LOCATION.  P2.3's plan carries tray1 to location9
     and never sets it down.  tech/tray.lisp documents this as the one
     deviation from held cargo having no location (a held tray's riders need
     it).  Specification 12.2 stated the premise for all cargo, from
     pickup-box only; it is amended (12.7).  The goal is unchanged: for a
     tray, "outside its start region" can be met by carrying it there.
  b. P3.2 needed 8 actions, not the 5 of the hand bound (reach location7 in
     4, pick up tray1).  No plan was found at cutoffs 5-7.  The plan found
     first steps the ghost off plate1, walks it back to location1 (the
     recorder), picks up tray1 and ends with the action STOP-RECORDER.
     Explained with D's domain answers (2026-09-26):
       - START-RECORDER forks a ghost of every mobile object (ledger pr11:
         all four ghost occupants have locations once a cycle is open), so
         tray1* rests on plate2 as tray1 does.  While a recording cycle is
         open, tray1* stays on plate2 and keeps it pressed after agent1
         lifts the live tray (D; S2: DEPRESSED reads every occupant, ghosts
         included).  The 5-action path therefore never makes plate2 free.
       - The ghost has to return to the recorder before the cycle can be
         stopped in the playback phase, unless the live agent reaches the
         goal, in which case playback terminates (D).
       - "Stopping" is ambiguous: a cycle has three phases, and each phase
         stops before the next begins (D).  This record names the action
         STOP-RECORDER and makes no claim about which phase boundary it
         marks.
     The hand bound was wrong because it treated the live tray as plate2's
     only occupant.  P1.4's 4-action plan is unaffected: its goal reads
     only agent1's location.  Lesson for hand bounds (not a schema gap):
     inside an open cycle, a support is free only when its ghost-layer
     occupants are gone too.

     to 467,635).  From this start the depth-11 space is nearly goal-
     independent, and small: no memory risk at this depth for crelay-topo.

     plan  truncated 0  states T"): the no-plan branch of its FORMAT
     directive did not consume the plan-length argument.  Fixed after the
     run with ~*.  Display only: the records and the report were correct.
