```lisp
(stage windtunnel-topo)
(ww-set *threads* 16)
(stage "doc/constraint-method/evidence/problem-t38-probe.lisp")
(load "tech/constraint-profile.lisp")
(load "tech/constraint-probe-battery.lisp")
(ensure-directories-exist ".t38-work/legacy.lisp")
```

compile the battery after staging, assert WARNINGS-P and FAILURE-P are NIL,
and load the resulting FASL before the checks. Remove the temporary directory
afterward. The checks write the retained result file below.
