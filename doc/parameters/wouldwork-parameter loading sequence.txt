WOULDWORK PARAMETER LOADING SEQUENCE

START: System Loading
(quickload :wouldwork) or (asdf:load-system :wouldwork)
    ↓
STEP 1: ww-preliminaries.lisp loads
    ↓
Call read-init-vals(vals-file)  [eval-when :load-toplevel]
    ↓
Decision Point: Does vals.lisp exist?
    ├─ NO → Return nil
    └─ YES → Read vals.lisp parameter list
             Set *problem-name* (position 0)
             Set *algorithm* (position 2)
             Set *debug* (position 11)
             Set *threads* (position 13)
             Set :ww-debug feature flag if (*debug* > 0)
             Return problem-name string
    ↓
File Management Logic:
    ↓
Decision Point: Does problem.lisp exist?
    ├─ NO → Copy problem-blocks3.lisp to problem.lisp
    │       Delete vals.lisp (will be rebuilt in step 5)
    │       END file management
    └─ YES → Decision Point: Does vals.lisp exist?
             ├─ NO → END file management
             └─ YES → Decision Point: Does problem-<vals-problem-name>.lisp exist?
                      ├─ NO → Delete inconsistent vals.lisp
                      │       END file management
                      └─ YES → Copy problem-<vals-problem-name>.lisp to problem.lisp
                               END file management
    ↓
Call reset-global-hash-tables()  [eval-when :load-toplevel]
    Runs AFTER read-init-vals so *threads* is correct.
    For each global hash table:
        RECREATED (tables with :synchronized flag) → setf to fresh hash-table
                  using (> *threads* 0) for the :synchronized argument
        CLEARED   (fixed or absent :synchronized)  → clrhash
    Also resets global lists (*query-names*, *update-names*, *actions*, etc.)
    and *last-object-index*.
STEP 2: ww-settings.lisp loads
For each parameter with define-global:
    ↓
Decision Point: Is parameter already bound?
    ├─ YES → Keep current value (from step 1 or previous)
    └─ NO → Set to default value
STEP 3: problem.lisp loads
For each (ww-set parameter value) statement:
    ↓
Decision Point: Is parameter compilation-critical?
    ├─ *debug* → ERROR: "Remove from problem file, set at REPL"
    ├─ *algorithm* → ERROR: "Remove from problem file, set at REPL"
    ├─ *probe* → ERROR: "Remove from problem file, set at REPL"
    └─ Other parameters → Set parameter = value
                         Override any previous value
STEP 4: ww-initialize.lisp loads
    ↓
(init)
    ↓
System initialization tasks performed...
    ↓
Decision Point: Does vals.lisp exist?
    ├─ YES → Call read-globals()
    │        Read all parameters from vals.lisp
    │        **OVERRIDE ALL current parameter values** ← KEY POINT
    └─ NO → Call save-globals()
            Save current parameter values to new vals.lisp
    ↓
Call display-current-parameters()
    ↓
END: loading complete, all parameters finalized

NOTE ON *threads* BOUNDARY CROSSING (0 ↔ non-zero):
(ww-set *threads* N) at the REPL detects when N crosses the 0 boundary.
It saves the new value to vals.lisp and performs an automatic full system
reload (asdf:load-system :force t), which re-enters this sequence from
STEP 1. This ensures:
  - Hash tables are recreated with the correct :synchronized flag.
  - Macros (increment-global, push-global, etc.) are recompiled with the
    correct atomic vs non-atomic expansion.
No SBCL restart is required.
