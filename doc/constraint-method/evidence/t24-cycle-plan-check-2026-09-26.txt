1.2  Encoding rules (A's technical choices)

- One segment per interval in which a set of devices must be active at the
  same time: a gated walk, a lift, a crossing, or the lit state.  Intervals
  that need no device (moves inside a region, pickups, placements) are not
  segments.
- Recording segments are the ghost's own gated moves; they read the
  recording view, where only ghost bodies hold plates.
- :held pins only the plates a required device needs, with every body the
  replay shows on that plate.  Bodies on plates no required device needs are
  not listed.
- :available-witnesses is () throughout: D's plan pins every required plate,
  so no plate is left to the matching.
- :off-plate lists the bodies the segment uses off plates (crosser, carrier,
  held cargo, relays); it is read only by B3.
- Every segment inside a cycle has :cycle :open and :ghosts :present; the
  plan has no segment outside a cycle (every stage is a recorder cycle, and
  the final leg runs while cycle 3 is still open).
