Standalone checkpoint implementation -- 2026-09-21
================================================
Approved by D after the proposal to replace repeated serial restart searches
with persisted checkpoints and standalone parallel searches.

API: capture-search-checkpoint, import-search-checkpoint,
export-search-checkpoint, search-checkpoint-state, validate-search-checkpoint.
The existing two-argument solve-subgoal now also accepts a checkpoint object.
Success returns a new object and T; exhaustion returns the original and NIL.
Search-found segments are not routinely replayed. Import replays each segment;
final validation replays the cumulative path against the original goal and
requires exact endpoint equality. The old chain persistence API remains available.
